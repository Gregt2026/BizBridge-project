# BizBridge

##  Overview
**BizBridge** is a platform designed to help small businesses build and manage their digital presence. It provides tools for website creation, user analytics, and business profile management — all in one place.

---

##  Features
- Business Profile Creation
- Website Builder
- Dashboard Analytics
- User Authentication & Login
- Mobile-Friendly UI (SwiftUI)

---

## Tech Stack
- **Language**: Swift
- **Framework**: SwiftUI
- **Platform**: iOS/macOS
- **Tools**: Xcode, Git, GitHub
